## 1. Grokking (학습시간 축 창발)

mod-97 산술, 50% train split, wd=1.0, d=512, K=8:

```
            train 90%   val 90%    지연        최종 val
곱셈        19,500      36,250     16,750      94.1%
덧셈        22,250      (미도달)   진행 중      84.8% (상승 중)
트랜스포머  500         1,500      1,000       100%
```

- 훈련 정확도 100% 도달(순수 암기) 후 검증 정확도가 한참 뒤 급등하는
  전형적 grokking 상전이. 에너지 하강 순환 모델에서 확인.
- 트랜스포머 대비 ~25배 느리게 grokking.
- 전제 조건: 비선형성(발견 2) + 충분한 폭(d=128은 암기조차 실패, d=512 성공
  — 정확한 임계 폭은 round 4 E2가 측정 중).

## 2. 선형성 결함 (왜 round 1이 실패했나)

`E(x) = ½‖u−Dx‖²_Π1 + ½‖(I−M)x‖²_Π2 + ½λ‖x‖²` 는 x의 2차식
→ `∂E/∂x`가 x에 선형 → K번 하강해도 토큰당 갱신은 아핀 변환
→ (M의 쌍선형 항 제외하면) 모델 전체가 선형 시스템.
mod 연산은 비선형 특징(푸리에 기저 등)이 필요하므로 원리적으로 불가능.
실험적으로도: 트랜스포머는 500 step에 암기 완료, 선형 PRISM은 60k step에
train 13%.

수정: 사전을 비선형화 — `E = ½‖u − D·tanh(x)‖²_Π1 + …`
(에너지 하강 원리는 유지; ∂E/∂x에 σ′(x) 체인룰 항 추가).
preflight(mod-23 암기): 선형 89% vs 비선형 99.7%.

## 3. K-취성: 평형 해가 아니라 회로 해

round-3의 grokked 모델(K=8 학습)을 다른 K로 평가:

```
K       1     2     4     8      12    16    32    64
acc     .009  .010  .005  .848   .097  .012  .010  .009
loss    4.6   4.6   4.6   0.72   4.7   NaN   NaN   NaN
```

- step 크기를 K·step=일정으로 재조정해도 복구되지 않음.
- 해석: BPTT-through-unrolled-descent 학습은 "에너지 최소점을 찾는 법"이
  아니라 "정확히 8번 반복하는 고정 깊이 계산"을 학습한다. grokking으로
  얻은 일반화 능력조차 이 회로에 갇힌다.
- DEQ/에너지 모델의 anytime 추론("K 크게 = 더 깊은 사고") 주장에 대한
  구체적 반례. **대응**: round 4 E6 — 학습 중 K~U{4,16} 무작위 샘플링으로
  K-불변 해를 강제. 성공 시 "더 오래 생각 → 더 정확"의 실측 여부 확인.

## 4. 비선형성 vs 시간 병렬 학습 트릴레마

비선형 수정의 대가: 선형 점화식 `x_t = A x_{t-1} + B u_t`는 결합법칙으로
parallel scan(시간축 병렬 학습, Mamba/linear attention의 기반)이 가능하지만,
`x_t = f(x_{t-1}, u_t)` 비선형이 되면 순차 처리만 가능.

이는 우연이 아니라 필연에 가깝다. 다음 셋은 동시에 가질 수 없다:

1. 상수 메모리 순환 상태
2. 시간축 병렬 학습
3. TC⁰를 넘는 비선형 상태 추적 (군 연산 합성 = mod 산술이 정확히 이 부류)

트랜스포머는 ①을 포기(KV 캐시 증가), 선형 SSM은 ③을 포기(→ round-1
PRISM의 실패와 동일한 이유), 현재 PRISM은 ②를 포기.

### 탈출구 (round 5+ 후보)

**(a) 비선형을 토큰 안에 가두기 — 유망.** 토큰 간 의존을 x 이월과 M 쓰기
두 경로에서 M 하나로 줄인다: x를 토큰마다 리셋하고 기억을 M(delta rule,
쌍선형)에 전담시키면 토큰 간 결합이 chunk-병렬 가능한 형태가 되고,
tanh K-루프는 토큰 내부에만 남는다. 트랜스포머의 "토큰 간 선형 어텐션 +
토큰 내 비선형 MLP" 분업의 에너지 버전. 검증 필요: M-경유 기억만으로
mod 산술의 상태 추적이 가능한가? (grokking 유지 여부가 판정 기준)

**(b) 시퀀스 전체를 하나의 에너지로.** E({x₁…x_T})를 정의하고 전 토큰
상태를 동시에 경사하강(Jacobi/Picard 반복: 스텝마다 전 토큰 병렬, 보통
반복 횟수 ≪ T). 비선형 RNN의 시퀀스 병렬화 연구들과 같은 접근이며
"모든 것은 같은 에너지의 하강"이라는 PRISM 명제와 자연스럽게 합치.

**(c) 현실적 우선순위.** 현재 스케일에서는 병렬화가 병목이 아님(P100
실험은 커널 런치 오버헤드 지배). 긴 시퀀스 LM(로드맵 4단계) 전에 (a)를
검증하는 것이 순서.

## 5. 엔지니어링 교훈

- **fast weight 분해 저장**: M = Σ_t c_t ε_t x_tᵀ 를 외적 이력으로 보관,
  Mv/Mᵀv는 O(B·T·d)로 계산 (dense 갱신과 수치 일치 자기검증 포함).
  (B,d,d) 실체화 대비 메모리·속도 모두 이득 → d=512 가능해짐.
- **eta(기억 쓰기 강도)는 sigmoid로 유계화**: softplus는 1.15까지 폭주하며
  학습 불안정 유발.
- **lr은 폭에 따라 스케일** (∝ 1/√d) + 발산 시 반감 자동 재시도.
- **P100(sm_60) 대응**: 최신 torch 휠은 sm_60 커널 미포함
  (`no kernel image available`). 시작 시 CUDA 연산을 실제로 실행해보고
  실패하면 torch==2.4.1+cu121 재설치 후 re-exec (`bootstrap_torch()`).
- 하강 루프 안에서 `.item()` 호출 금지 (host sync가 GPU 처리량 붕괴).


## 6. 심층 분석 (round-3 데이터, 2026-07-11)

그림: `results/round3-analysis/analysis_f{1..4}_*.png` (생성 스크립트 동봉)

**(a) 신기루 검증 통과 — 진짜 동역학 전이.** mod-97 곱셈에서 연속
지표(val loss)가 암기기에 4.6→6.0으로 악화했다가 상전이 구간에서
5.6→0.3으로 비단조 급락. 이산 지표의 착시(Schaeffer의 mirage 비판)로
설명 불가. 상전이 상대 폭 0.81로 트랜스포머(1.00)와 대등하게 급격.

**(b) 일반화 규칙이 기억 회로 위에서 동작.** grokked 체크포인트(val
85.9%)에서 fast weight 절제 시 1.1%로 완전 붕괴 (eta를 0.01로 줄여도
동일). 규칙이 slow weight로 증류된 것이 아니라 테스트타임 Hebbian
쓰기가 계산 경로의 필수 부품. eta 궤적(0.15→0.69 성장, 상전이 후
0.61로 이완)과 일관. "지각·기억·추론이 같은 에너지에서 얽힌다"는
명제의 실증이자, K-취성의 원인 후보(M에 쓰이는 내용이 K=8 중간
상태에 캘리브레이션됨).

**(c) 기억의 recency 병목.** E4 용량 격자에서 정확도 × n_pairs ≈
0.76 ± 0.1 로 일정 (d=32/64/128 × pairs=2~16 전부). d를 4배 키워도
불변 → M이 사실상 "최근 1쌍 레지스터"로 작동하며 이후 쓰기가 이전
쓰기를 간섭으로 지움. 병목은 용량이 아니라 간섭 관리 → 해법은 d
스케일업이 아니라 쓰기 게이팅(선택적 기억) 또는 직교화된 키 공간.
round 5+ 과제.
